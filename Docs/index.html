Quick 2-Minute Installation

  1. Download the latest release ZIP: sahayak-extension.zip.
  2. Unzip the archive to a local folder on your computer.
  3. Open Chrome and navigate to chrome://extensions.
  4. Toggle on Developer mode in the top-right corner.
  5. Click Load unpacked and select the unzipped directory.
  6. Pin Sahayak and open the Side Panel to configure your free Gemini API key in Settings.
